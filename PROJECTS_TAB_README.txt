MALIXARIS STUDIO — PROJECTS TAB PATCH

Files in this patch:
  web/studio.js
  web/studio.css

Install:
1. Close MalixAris Studio.
2. Extract this ZIP into the existing MalixAris Studio application folder.
3. Allow the two files in the web folder to be replaced.
4. Start the application again.

What was added:
- A Projects tab in the left navigation.
- Five editable starter templates: YouTube Documentary, Gaming Montage,
  Product Promo, Educational Explainer and YouTube Shorts.
- Preview Structure expands the outline before loading it.
- Use Template loads a numbered sample script into Create Project and applies
  the template's suggested resolution and frame rate.
- The current script is not replaced unless the user confirms.
- The loaded script remains editable in the existing Script editor.

Important:
These are starter project structures, not finished videos. Users still need
select their own footage folder and voiceover, then edit the sample narration.
No existing project files, source media, settings or output files are deleted.
